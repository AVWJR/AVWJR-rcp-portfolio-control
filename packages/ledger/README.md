# @rcp/ledger

General ledger: master CoA (including CIP `1460`), double-entry validation, trial balance, income statement, balance sheet, cash flow, period-close rules, intercompany matching, the deal LP/GP distribution waterfall (`waterfall.ts`), and deal/OpCo proformas (`proforma.ts`). Amounts are integer USD cents. Optional Co-GP splits the GP side (RCP vs third party); Co-GP share 0 matches the prior two-party model.
